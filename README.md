# 🎬 CineWave

Проект создан для удобного просмотра фильмов и получения умных рекомендаций.

## ✨ Основные возможности
* **Каталог фильмов:** удобная сетка с постерами и базовой информацией.
* **Плеер:** встроенная страница для просмотра выбранного контента.

## 🛠 Стек технологий
* **HTML5** — семантическая разметка страниц.
* **CSS3** — стилизация, сетки (Flexbox/Grid) и анимации.
* **JavaScript (Vanilla JS)**
